# Algoritmo Genético: painel completo

**O que a imagem mostra:** reúne numa só figura as imagens separadas desta execução. Os números de cada parte estão nas notas de mesmo prefixo indicadas abaixo.

| parte | nota com os números |
| --- | --- |
| sucessão da melhor rota | `sucessao` |
| custo ao longo da busca | `custo` |
| convergência da população | `populacao` |
| quadro-resumo | `resumo` |
